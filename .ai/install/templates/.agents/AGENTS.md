# AI-Kit agent entry point

Read and follow the repository-root `AGENTS.md` before planning, editing,
reviewing, or delivering work. It is the sole normative instruction source.

For an assigned task, run `ai-kit route <task-id>` and read the returned active
procedure before policy/core skills or technology packs. The eight procedure
SOPs use the mandatory sections `INPUTS`, `PRECONDITIONS`, `ACTIONS`,
`OUTPUTS`, `VALIDATION`, and `FORBIDDEN`; workers must not bypass the
control-plane lifecycle gates described in root `AGENTS.md`.
